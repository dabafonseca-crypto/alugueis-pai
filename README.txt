Arquivos:

WEB:
Publique todos os arquivos juntos em um site HTTPS (ex.: GitHub Pages).

ANDROID:
Depois de publicado, abra o endereço no Chrome do Android.
Use: menu ⋮ > Adicionar à tela inicial / Instalar app.
O aplicativo abrirá em modo próprio, com ícone e sem tela de login.

Observação:
A chave presente no HTML é somente a Publishable Key do Supabase.
Nunca colocar a Secret Key no frontend.
